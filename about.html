About CardioShield Architecture & Model

An overview of the machine learning pipeline, clinical dataset, technology stack, and engineering implementation.

End-to-End System Architecture

The system follows a decoupled microservices architecture connecting a responsive frontend client to a Flask predictive API engine powered by DictVectorizer feature encoding.

Frontend UI

HTML5 / CSS3 / JS Form

Flask REST API

POST /predict JSON Endpoint

DictVectorizer

One-Hot Categorical Encoder

Logistic Regression

Scikit-Learn Binary Classifier

Dataset & Clinical Parameters

The model is trained on combined clinical heart disease datasets (including UCI Heart Disease dataset) containing 918 patient observations across 11 core clinical parameters:

Demographics
Age (Years) & Sex (M/F)
Vitals
Resting BP & Cholesterol
Glucose
Fasting Blood Sugar (0/1)
ECG Scan
Normal, ST, or LVH
Stress Test
Max HR & Exercise Angina
ST Segment
Oldpeak & ST Slope

Machine Learning Model Specifications

ALGORITHM
Logistic Regression

Optimized with Liblinear solver for binary probability classification.

FEATURE ENCODER
DictVectorizer

Handles one-hot encoding of categorical variables seamlessly.

EVALUATION METRIC
ROC-AUC > 0.92

Evaluated on cross-validation split for high sensitivity.

Technology Stack
